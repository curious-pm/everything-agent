## [0.1.0]

First public release.

### Added

- Hands-free voice conversation with Reachy Mini: no wake word, streaming speech-to-text,
  language model and voice, with head movement while Reachy speaks.
- Replies in the language you speak (English, Hindi, French, Spanish, Japanese), or always in one.
- Talking over Reachy to interrupt it, off by default.
- Hard questions handed to Claude Code in the background, answered aloud when ready.
- Works with any OpenAI-compatible model provider or a local Ollama model.
- Runs on the robot, as a Windows and macOS desktop app, and in any browser on the network.
- Web page protected by a PIN, with lockout after repeated wrong PINs.
- Settings page for keys, model, voice, language, microphone and speaker.
